# AppStatistic 管理端实施记录

默认应用：apps/web-antdv-next。路由包含总览、活跃、设备、版本、渠道、页面、留存、事件、设备明细及设备详情。

## 已实现

- 九项总览指标、趋势切换、图表筛选、URL 查询同步、权限路由、中英文文案、空数据与错误重试。
- 事件完整字段筛选和 JSON 查看；设备组合条件查询、分页上限 100、详情最近会话与事件。
- ECharts 留存热力图及按 cohort 人数加权的趋势，尚未成熟周期保持空白，提示显示基准及留存人数。
- 后端概览读取已有每日汇总，GET 不重建；显式重建记录 WAU/MAU，修正页面 UV，补充设备筛选及版本日期。
- 渠道表提供新增用户、新增设备及启动次数。新增用户和启动次数由显式日重建写入已有 ExtraProperties；旧数据重建前显示缺失值。新增用户按当日首次使用 App 且在该渠道产生事件计数，同日多渠道可能重复。新增设备按当前设备渠道归属计数。
- 主 Host 加载 AppStatistic Application、HttpApi、EntityFrameworkCore 模块。

## 尚未满足原文档的项目

- 跨平台、版本、渠道的准确交叉聚合没有对应日事实数据；汇总页面隐藏不支持的筛选，接口拒绝这些条件。设备与事件明细支持可用条件组合。
- 页面停留时长没有采集来源，显示缺失值。

- AppId 使用输入框；尚无应用注册列表、应用时区或自动每日聚合任务。
- 设备厂商、型号及系统版本使用当前设备资料；历史渠道归因存在同样限制。
- 部分分析仍使用限定日期的事件查询，尚未验证百万级数据的响应时间。
- 未同步旧 web-antd 应用；未生成 Migration，未执行真实数据库更新。
